# Prompt injection

Prompt injection is an attack class where untrusted content tries to redirect or manipulate an agent's instructions. In this source, prompt injection appears as a key safety concern for [[computer-use-in-llms|computer use in LLMs]] systems.

The announcement says the feature includes user confirmation, auto-stop on prompt injection, and extra training against prompt injection. That framing suggests prompt injection is one of the main barriers to deploying agents that can act on real user interfaces.
