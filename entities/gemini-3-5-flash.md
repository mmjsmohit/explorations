# Gemini 3.5 Flash

Gemini 3.5 Flash is a Google model that, in the current wiki sources, is presented as the host for [[computer-use-in-llms|computer use]] across browser, mobile, and desktop environments.

The initial announcement frames the capability as native to the main model and emphasizes safeguards such as user confirmation and auto-stop on [[prompt-injection|prompt injection]]. Phil Schmid's Android walkthrough adds operational detail: the `mobile` environment can drive an Android emulator by reading screenshots, emitting structured actions, and relying on an ADB-backed execution bridge to carry them out.

Together, these sources make Gemini 3.5 Flash relevant here both as a model release and as a practical agent runtime surface for UI automation, documentation testing, and emulator-based task execution.
