# Gemini 3.5 Flash

Gemini 3.5 Flash is a Google model that, in this source, is presented as the host for a new [[computer-use-in-llms|computer use]] capability.

The post describes the feature as built into the main model and emphasizes safeguards such as user confirmation and auto-stop on [[prompt-injection|prompt injection]]. It also claims support for browser, mobile, and desktop environments. These details come from a single announcement post, so they should be treated as provisional until corroborated.
