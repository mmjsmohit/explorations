# Manus AI

Manus AI is the agent system referenced in the webinar and blog post that motivated this wiki entry. The talk presents Manus as an example of using context engineering to balance reduction, isolation, and offloading in a real product.

## What the talk emphasizes

- Keep the boundary between application and model clear.
- Use retrieval and offloading to manage working memory.
- Prefer simplification over adding more context.
